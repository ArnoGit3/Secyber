Vulnerable Mode Pattern

# String interpolation vulnerability
query = f"SELECT id, name, category, price FROM products WHERE name LIKE '%{search}%'"
cur.execute(query)

Secure Hardened Pattern

# Parameterized prepared statement
query = "SELECT id, name, category, price FROM products WHERE name LIKE ?"
cur.execute(query, (f"%{search}%",))

Technical Audit Analysis

Direct concatenation of user input into dynamic SQL strings merges input data with SQL grammar. Attacker-supplied strings containing SQL control characters (such as single quotes ' or comment markers --) alter the SQL execution tree. Prepared statements separate code compilation from data evaluation, neutralizing injection vectors regardless of input structure.
