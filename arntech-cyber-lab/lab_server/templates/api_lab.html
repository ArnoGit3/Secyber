Technical Audit Analysis

  • Broken Object Level Authorization (BOLA): APIs must validate requestor identity and object ownership on every endpoint.
  • Excessive Data Exposure: Returning backend models directly to clients leaks sensitive token metadata and internal fields.
  • API Key Header Enforcement: Mandatory validation of custom API authentication headers (e.g. X-ARNTECH-API-KEY) before servicing requests.
