Vulnerable Mode Pattern

# Dangerous shell concatenation
command = f'echo "Audit host: {host_input}"'
subprocess.run(command, shell=True, ...)

Secure Hardened Pattern

# Safe fixed argument list
args = ["echo", "Host audit complete (SECURE: fixed argument array)"]
subprocess.run(args, capture_output=True, ...)

Technical Audit Analysis

Invoking system processes with shell=True passes user-controlled strings to shell interpreters (such as /bin/sh or cmd.exe). Shell metacharacters (;, &&, |, `) break out of expected arguments and execute arbitrary operating system commands. Secure process management avoids shell interpreters entirely by invoking binaries directly with fixed argument arrays.
