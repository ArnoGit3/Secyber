Technical Audit Analysis

  • Strict Extension Allowlisting: Accept only explicitly permitted static file extensions (e.g. .png, .jpg, .pdf, .txt). Reject executable or script extensions.
  • File Size Quota: Enforce maximum upload size (e.g. 2 MB) to prevent resource exhaustion and denial-of-service.
  • Filename Sanitization: Use secure_filename() to strip path traversal sequences (e.g. ../../).
  • Isolated Storage Directory: Store uploaded files in a non-executable directory outside web server document root.
