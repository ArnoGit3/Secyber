Technical Audit Analysis

In vulnerable mode, untrusted HTML output bypasses template escaping via explicit raw rendering (| safe). This allows attacker-supplied JavaScript payloads (e.g. <script> or event handler attributes) to execute within the session context of any visiting browser. Enforcing strict contextual output encoding transforms HTML control characters (<, >, ", &) into safe inert entities, preventing DOM execution.
